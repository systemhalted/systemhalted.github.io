* Timeline
| Year | Event |
|-
| 1964 | Multics project begins — the ambitious ancestor of Unix |
| 1969 | Unix is born at Bell Labs (Thompson & Ritchie) |
| 1973 | Unix rewritten in C — portability changes everything |
| 1974 | CP/M arrives — the OS that ruled early microcomputers |
| 1981 | MS-DOS 1.0 ships with the IBM PC |
| 1984 | Apple Macintosh brings the GUI to the masses |
| 1985 | Commodore Amiga & Windows 1.0 both debut |
| 1987 | OS/2 — IBM and Microsoft's brief alliance |
| 1991 | Linus posts 'just a hobby, won't be big' — Linux begins |
| 1993 | Windows NT and FreeBSD/NetBSD set the modern stage |
| 1995 | Windows 95 — Start me up |
| 2000 | BeOS open-sourced as Haiku; Windows 2000 lands |
| 2001 | Mac OS X (NeXT lineage) and Windows XP arrive |
| 2007 | iPhone OS & Android — the OS goes mobile-first |
| 2008 | The cloud era: the OS quietly becomes a fleet |
